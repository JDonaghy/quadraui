# quadraui website

mdBook source for <https://jdonaghy.github.io/quadraui/> (quadraui#1349).

- `src/introduction.md`, `src/getting-started.md` — hand-maintained.
- `src/gallery/` and `src/SUMMARY.md` — generated by `../tools/site_gen.py`;
  never edit them directly, they're overwritten on every build (see
  `book.toml`'s own comment, and `.gitignore`).

## Build locally

```sh
# From the repo root:
cargo run -p quadraui-gallery --features tui -- --dump-registry /tmp/quadraui-site/registry.json
cargo run -p quadraui-gallery --features tui -- --capture /tmp/quadraui-site/capture-tui
python3 tools/site_gen.py \
  --registry /tmp/quadraui-site/registry.json \
  --capture /tmp/quadraui-site/capture-tui \
  --out site/src
mdbook build site   # needs `mdbook` on PATH: `cargo install mdbook` or `brew install mdbook`
mdbook serve site   # or: live-reload at http://localhost:3000
```

`.github/workflows/pages.yml` runs the same four commands on every push to
`develop` and deploys `site/book/` to GitHub Pages.
