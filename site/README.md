# quadraui website

mdBook source for <https://jdonaghy.github.io/quadraui/> (quadraui#1349,
#3076).

- `SUMMARY.template.md` — the site's navigation, hand-maintained. Its
  `<!-- site_gen:gallery -->` line marks where the generated gallery goes.
- `src/**/*.md` — hand-written pages: introduction (mirrors the README's
  first screen), quick starts, concepts, bindings, links.
- `src/images/hero-*.png` — the hero counter on each backend, from
  `../scripts/capture_hero.sh`. Commit regenerated images.
- `src/gallery/` and `src/SUMMARY.md` — generated by `../tools/site_gen.py`;
  never edit them, they are overwritten on every build (and gitignored).

Every Rust, Python or TypeScript sample on a page sits under a
`<!-- sample: <file> -->` comment naming the file CI builds it from, or
`<!-- sample: untested — <reason> -->`; `../tools/test_doc_samples.py`
enforces that.

## Build locally

```sh
scripts/site_gallery.sh tui,gtk   # from the repo root; tui,macos on a Mac
mdbook serve site                 # live reload at http://localhost:3000
```

`site_gallery.sh` captures the gallery, generates the pages, runs
`mdbook build site` and checks every link. It needs `mdbook` on `PATH`
(`cargo install mdbook` or `brew install mdbook`).
`.github/workflows/pages.yml` runs the same steps on every push to
`develop`, adds the macOS and Windows columns from CI's capture jobs, and
deploys `site/book/` to GitHub Pages.
