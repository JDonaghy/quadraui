- The docs site (jdonaghy.github.io/quadraui) is rebuilt for the 0.12 launch
  (#3076): five-minute quick starts for Rust, Python and Node that end in a
  terminal app and a native window; Concepts pages (widgets, events, layout,
  state, focus, popups, theming), each mapped onto Elm, iced, React and
  Textual; a bindings page lining up the three languages and linking the
  generated wire types; and a widget gallery with one page per group that
  shows every widget on every backend. `scripts/site_gallery.sh` regenerates
  the gallery and builds the site, `site/SUMMARY.template.md` is the
  hand-written navigation, `tools/check_site_links.py` fails the deploy on a
  broken link, and `tools/test_doc_samples.py` checks that every code sample
  on the site and in the README is a copy of a file CI builds or runs.
