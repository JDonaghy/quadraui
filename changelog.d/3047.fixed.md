- `DualModePalette` no longer swallows an unmodified `j`/`k` in List mode,
  so a search query can contain them (#3047). Vim-style highlight moves are
  opt-in through `DualModePalette::vim_keys`/`with_vim_keys`, routed by the
  same palette-host key prelude the path pickers use. `Chat` floors a
  hand-set `input_rows` (`min` to 1, `max` to `min`) instead of panicking.
