- `CellGridController` clipboard support (#2729): `copy_selection` writes
  the current selection's displayed text to the platform clipboard as TSV
  (tab-separated within a row, newline-separated across rows), via the new
  `CellGrid::range_as_tsv`; `cut_selection` does the same and additionally
  reports `CellGridControllerEvent::CutRequested` for the host to clear the
  range through its engine; `paste` reads the clipboard and reports
  `CellGridControllerEvent::PasteRequested` with the current selection's
  top-left anchor plus the clipboard text, for the host to parse and apply.
  The controller still owns no cell content itself — all three take the
  host's real `CellGrid`/`Clipboard` directly rather than going through
  `CellGridController::handle`. `range_as_tsv`'s cost is bounded by the
  loaded window (`CellGrid::cells_window`), not by the selection's
  absolute size, so Ctrl+A then Ctrl+C on a virtualised sheet never
  materialises the whole sheet: rows/columns outside the loaded block are
  dropped from the result rather than padded with an empty placeholder.
