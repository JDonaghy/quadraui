- A bare `Dialog`'s button row now paints at `Style::control_height` on a
  pixel backend instead of the raw chrome line height, matching
  `MessageDialogController`'s OK/Cancel row (#2490): new
  `Dialog::measure_generic_with_style` and
  `Dialog::measure_generic_measured_with_style` helpers size
  `DialogMeasure::button_row_height` from `Style::control_height`
  whenever `line_height > 1.0` (TUI's `line_height == 1.0` char-grid
  geometry is unchanged), and `quadraui-gallery`'s `DialogDemo` now
  derives its button row the same way, so its macOS/GTK/Win capture
  shows the same button height as the gallery's `MessageDialog` demo.
  The button row's corner radius (`Style::button_radius`) was already
  unaffected — `native_surface_paint::paint` resolves it via
  `ButtonMetrics::resolve` regardless of row height.
