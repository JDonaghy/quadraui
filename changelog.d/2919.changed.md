- `quadraui-binding-core`'s `cell_grid` wire extra (#2919): migrated off the
  cached `CellGridController`/`CellGridControllerDescriptor` onto the generic
  `DynWidget`/`WIDGET_KINDS` leaf seam #2904 built for `icon_grid` — a
  `cell_grid` leaf now decodes straight into `quadraui::CellGrid` (no more
  per-id controller cache in `InteractionEngine`) and its navigation/editing/
  virtualisation outcomes arrive as `UiEvent::CellGrid(id, CellGridEvent)`,
  dispatched through the same generic path every other `WIDGET_KINDS` member
  uses rather than a bespoke `dispatch_cell_grid_controller` `EventSink`
  method. `quadraui::primitive::DynWidget` gained `as_any`/the inherent `dyn
  DynWidget::downcast_ref` helper, so a caller that needs a widget-specific
  method the trait doesn't erase (`CellGrid::cells_requested`) can still reach
  it. `InteractionEngine` also gained a generic pointer-capture seam
  (`EventHost::capture_pointer`/`release_pointer`, previously a no-op) and now
  dispatches `UiEvent::FocusChanged` on a `WIDGET_KINDS` click-to-focus, both
  needed for `CellGrid`'s own click-and-drag range selection and usable by any
  future `WIDGET_KINDS` member. `wire_schema.rs` (and the generated
  `wire.pyi`/`wire.d.ts`/`docs/bindings-wire-format.md`) replace
  `CellGridControllerDescriptor` with `CellGridDescriptor`/
  `CellEditStateDescriptor` and add the `CellGridEvent` tagged union a
  `quadraui-py`/`quadraui-node` host now receives instead of the old
  `{"CellGridController": [id, event]}` shape. A paste with no active edit now
  starts a single-cell edit seeded with the whole pasted text (via
  `CellGrid`'s own `RoutedEvent::Text` handling) rather than spreading a
  multi-cell TSV paste across the grid — `CellGridEvent` has no
  `PasteRequested` counterpart to the old `CellGridControllerWireEvent`'s.
