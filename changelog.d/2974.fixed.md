- Every editable text widget (`TextField`, `CommandLine`, the `Palette`
  query, `TextInput`, `Form`'s text rows and the `CellGrid` cell editor)
  now handles keys, text, presses, drags and focus through one shared
  handler, `behaviour::text_edit::handle_flat_edit_event` /
  `handle_lines_edit_event`. Fixes:
  - a Ctrl/Cmd chord that is not a clipboard chord (Ctrl+Z, Cmd+S, …) no
    longer types its letter into the field; it is left to the app's
    accelerators (`EditIntent::from_key` returns `None`; Ctrl+Alt still
    types, for AltGr);
  - a press-and-drag over a `TextField` or `TextInput` now selects the
    dragged-over text, as it already did on `CommandLine`;
  - a `TextField`, `CommandLine`, `Palette` or `Form` painted as a
    `Surface::Widget` now shows the caret and selection its own editing
    moved, instead of the descriptor's stale ones;
  - `Form` text rows and the `CellGrid` cell editor gain Ctrl/Cmd+A/C/X
    (a `PasswordInput` row never copies its value out).
- `TextDisplay`'s wheel scrolled the wrong way on the widget contract: a
  negative `ScrollDelta::y` (a notch toward later lines, the sign every
  other scroller reads through `wheel_row_delta`) moved it back up. It now
  reads the wheel through `wheel_row_delta` too.
