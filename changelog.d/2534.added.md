- `A11yInfo::description`/`A11yInfo::with_description` (#2534): a
  supplementary accessible description — ARIA's `aria-description` — read
  after an element's label, merged field by field alongside `a11y_label`
  and `live` through `crate::frame::OwnedNode::a11y` overrides, shown in
  an `A11yTree` snapshot as a `desc="..."` state token, and mapped onto
  `accesskit::Node::set_description` under the `a11y` feature. A binding's
  wire decoder (`quadraui-binding-core`) now accepts a leaf-only `"a11y":
  {"label": ..., "description": ..., "live": ...}` key, recording the
  decoded `A11yInfo` against the leaf's id in `DecodeDiagnostics`'s
  id-keyed `a11y_overrides()` side table for the binding to apply.
