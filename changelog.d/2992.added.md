- `TabBar` implements `Default` (an empty bar with the same field values a deserialised `{}` gets), so a struct literal can name only the fields it sets and end in `..Default::default()` (#2992).
- `FontRole::Icon` — an icon glyph painted beside chrome text (#2992) — **breaking** for exhaustive `match`es on `FontRole`. `Backend::measure_text` with this role measures in the font the backend paints icons in: GTK the chrome font plus its Nerd Font fallback family, macOS/Windows/TUI the chrome font. `TabBar`'s `Primitive::layout` measures tab icons with it, so on a pixel backend the icon columns it reserves match what `draw_tab_bar_icons` paints — before, GTK on macOS reserved each icon about 2px narrower than it painted.
