- A live runner can opt a backend into keeping the `OwnedFrame` (plus focus)
  from its most recent `ScreenLayout::draw`/`OwnedFrame::draw` call, via the
  new `FrameCapture` slot a backend hands out from `Backend::frame_capture`
  (`set_frame_capture(backend, true)` for the one-line form) (#2712).
  `Backend::last_frame` exposes the captured frame, off by default and costing
  nothing when left off; `backend_a11y_tree` turns it into an `A11yTree` from
  the real screen a TUI app just painted, not only from a test `A11yScenario`.
  TUI implements capture today — only the canonical `ScreenLayout` paint path
  (D-006) populates it.
