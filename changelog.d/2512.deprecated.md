- `Backend::draw_switch_with_state`/`Backend::draw_radio_group_with_state`
  (#2512): superseded by `Backend::draw_switch`/`Backend::draw_radio_group`
  now that `Switch`/`RadioOption` carry their own `hovered`/`pressed`
  fields — set those directly and call the plain method. Both deprecated
  methods keep their default body (clone the descriptor, copy the
  `InteractionState` onto it, delegate) so every existing caller keeps
  compiling unchanged.
