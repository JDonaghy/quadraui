- `BackendError` is now `#[non_exhaustive]` (#2780): a downstream `match`
  on `quadraui::BackendError` must add a wildcard arm (`_ => {}`) to keep
  compiling. Construction (`BackendError::Unsupported`,
  `BackendError::PlatformFailure { context }`) and single-variant
  destructuring (`if let BackendError::Unsupported = err`) are unaffected.
  `quadraui-binding-core`'s `From<BackendError> for ServiceError` was the
  only in-repo exhaustive match living outside the defining crate (every
  match inside `quadraui/src`/`quadraui/tests` is in-crate and needs no
  change); it now folds any future variant into `ServiceError::Failure`.
  Grepping `vimcode` and `coord-tui` found no exhaustive `BackendError`
  match lacking a wildcard arm already, so neither needs a migration.
