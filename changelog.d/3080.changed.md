- **Breaking (bindings):** the Python and Node `Tree` row-click callback is
  `on_click(path, button)` / `onClick(path, button)`, matching `List` and
  `Table`'s `on_click(idx, button)`, so an app can tell a middle or
  back/forward press from a left one; `on_row_click` / `onRowClick` is
  gone (#3080).
- A `FocusChanged` pushed into a binding app (a test harness's
  `focus(id)`) moves keyboard focus to that widget, so the keys that
  follow reach it; on a form, its first field (#3080).
