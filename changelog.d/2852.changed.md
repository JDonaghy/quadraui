- `ListView`'s `Primitive::paint`/`paint_cells` pilot now sources its
  hover/pressed/scroll/stripe/focus-ring paint inputs from a
  `ListPaintState` read through the `crate::primitive::PaintState` trait
  (#2852) instead of bare `None`/`false` literals. `PaintState` gains a
  new defaulted `focus_ring_visible` method (`false` for every existing
  implementor, non-breaking). `Primitive::layout`'s TUI/pixel-backend
  discriminator now compares a `crate::primitive::Units` value, via
  `LayoutCtx::units`, instead of a bare `line_height <= 1.0`
  check.
