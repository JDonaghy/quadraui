- Added `quadraui::control`, a backend-neutral control channel behind the
  new `control` cargo feature (#2714): a cloneable, `Send` `ControlHandle`
  lets a thread that does not own the event loop snapshot an app's
  accessibility tree, route an assistive-technology-style action against
  it, or synthesize key input, all serviced through the same
  `AppLogic::handle` dispatch path real input uses. Wired into the TUI
  runner (`tui::run::TuiRunner::attach_control`, and
  `tui::shell_runner::runner_with_shell` for `ShellApp`); GTK, macOS and
  Windows wiring lands in their own issues.
