- `TabBar` implements the widget-contract traits `Primitive` and
  `Interactive` (#2984), the backend-neutral seam for porting it onto
  `Surface::Widget`: `Primitive::layout` resolves a `TabBarLayout` from
  either the TUI cell measurer or `layout_metrics::pixel_tab_bar_layout`
  fed by `LayoutCtx::measure`'s char-width approximation,
  `Primitive::paint`/`paint_cells` call the module's existing
  `native_surface_paint::paint`/`cell_paint::paint` painters unchanged,
  and `Interactive::handle` folds `TabBar::handle_focus_key`'s
  Left/Right/Enter keyboard model directly into the generic
  `RoutedEvent` dispatch (`focus()` is `FocusSpec::Stop`, matching
  `ListView`/`CellGrid`). `"tab_bar" => TabBar` joins `widget_kinds!`,
  and `OwnedContent::TabBarWidget` lets a `TabBar` reached through
  `Surface::Widget` capture and hit-test like the live frame. The
  existing `Backend::draw_tab_bar*`/`tab_bar_layout*` methods and every
  per-backend `tab_bar.rs` file are unchanged; callers migrate in a
  follow-up slice.
