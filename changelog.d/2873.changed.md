- **Breaking:** `ContextMenu` gained a `glyphs: ContextMenuGlyphs` field
  (#2873), so the check-mark / submenu-arrow overrides ride the
  descriptor instead of being an extra painter argument. A popup painted
  as a `Surface::Widget` through `Primitive::paint`/`Primitive::paint_cells`
  — which take no glyph argument — now renders the same marks one painted
  through a backend wrapper does. Struct literals add
  `glyphs: Default::default()` (`{}` on the wire, or the key omitted
  entirely, keeps today's default `✓`/`▶`); a caller that passed
  `Some(&glyphs)` to a rasteriser still overrides the descriptor's own
  set.
- A context-menu row whose `detail` carries several styled spans now
  renders every span in its TUI shortcut hint (#2873), matching what the
  pixel backends have always shown; previously only the first span
  reached the cell grid.
