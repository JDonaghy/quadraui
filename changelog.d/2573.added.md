- `TuiBackend::kitty_graphics()` reports whether this session's terminal
  supports the Kitty graphics protocol with Unicode placeholders, plus the
  terminal's per-cell pixel size, for later rasterisers to build on
  (#2573). Detection seeds from a cheap environment check
  (`TERM=xterm-kitty`, `TERM_PROGRAM=ghostty`, `KITTY_WINDOW_ID`,
  `GHOSTTY_RESOURCES_DIR`) and is overwritten by a live protocol probe in
  `tui::run`, the same two-stage shape as `kitty_keyboard`/
  `probe_kitty_keyboard`; `QUADRAUI_TUI_GRAPHICS=off`/`kitty` overrides the
  answer in either direction. No rasteriser emits real Kitty graphics
  escape sequences yet — this only detects.
