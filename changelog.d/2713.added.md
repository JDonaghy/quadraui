- `A11yTree` and `A11yAction` now implement `serde::Serialize` (#2713),
  giving the accessibility tree a stable JSON form: a top-level `focus`
  field plus a `root` field holding the whole tree nested by `children`,
  where each node carries its stable id, `widget_id` (when the owner
  side-table has one), `role`, `label`, `description`, `value`, state
  flags (`focused`, `selected`, `expanded`, `checked`, `disabled`),
  `bounds`, and the actions `route_action` would accept for it. Node ids
  equal `A11yNodeId::for_widget`/`child`, so a caller can hand one
  straight back to `route_action` as an `act` target. `A11yInfo` gains a
  new optional `total_rows` field, surfaced on a windowed container's
  JSON node once a primitive's row-loading window populates it. See
  `quadraui/src/a11y/tree.rs`'s "Stable JSON form" module-doc section for
  the full shape and an example.
