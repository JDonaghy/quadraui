- `compose::TreeTableController` (#2599): a hierarchical-model controller
  over `TreeTable` — nodes keyed by a stable `NodeId` (not the positional
  `TreePath` a sort reorders), an expanded set, and lazy child loading
  (`TreeTableNodeData::lazy_branch` + `ChildrenRequested` + `set_children`,
  with a dim `…` placeholder row shown meanwhile). A header click
  (`header_clicked`) sorts every loaded level's children by that column's
  cell text, recursively, keeping the hierarchy intact; selection survives
  expand/collapse/sort because it's tracked by id, re-resolved against
  `TreeNavCore`'s positional path on every navigation call. Navigation,
  selection, scroll-to-follow, scrollbar drag, wheel scroll and
  Left/Right expand-or-select all go through `compose::tree_nav::TreeNavCore`
  — the same core `TreeController` uses for `TreeView` — rather than being
  re-implemented; the keyboard nav entry points skip the lazy-load "…"
  placeholder row the same way a mouse click on it already does. The
  gallery's "Tree Table" demo now builds on this controller instead of its
  own hand-rolled hierarchy/flatten/navigation.
