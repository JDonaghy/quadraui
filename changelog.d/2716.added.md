- Added "Level 2" app-level named commands to `quadraui::control` (#2716):
  `control::CommandRegistry` lets an app register named commands (e.g.
  `select(index)`, `count()`) that act on its own model rather than its
  widgets, and `AppLogic::command_specs`/`AppLogic::run_command` are the
  new default-bodied trait hooks an app overrides to plug one in.
  `control::ControlRequest::Command`/`ControlRequest::ListCommands` route
  through them for a *running* app over the control channel, and the new
  `control::cli::run`/`run_result` run one command from argv against a
  fresh app instance and print its JSON result, with no control channel,
  event loop, or backend at all. `quadraui-mcp`'s `tools/list` lists every
  registered command alongside its four built-in Level 1 tools, and
  `tools/call` routes any other name straight to it.
