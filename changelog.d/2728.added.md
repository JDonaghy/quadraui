- Added in-cell editing to `CellGrid`/`CellGridController` (#2728):
  typing a character or pressing F2 opens an inline single-line editor
  over the cursor cell, built on `TextField`'s own edit ops rather than a
  second line editor; Esc cancels; Enter/Tab/the arrow keys commit and
  move, as in Excel. The commit event is
  `CellGridControllerEvent::CellEditCommitted { row, col, text }` — the
  host hands `text` to its engine (e.g. `cell.set`) and supplies the new
  formatted value next frame. F2 has no cell content of its own to seed
  the editor with, so it emits `CellGridControllerEvent::CellEditRequested`
  instead, and the host calls the new `CellGridController::start_editing`
  with that cell's raw text. `CellGridController::sync_formula_bar` /
  `CellGridController::handle_formula_bar_key` keep an external `TextField`
  (a formula bar) mirroring the same in-progress edit and let it commit
  the same way. `CellGrid` gains a new `editing: Option<CellEditState>`
  field a TUI/pixel backend paints as the overlay.
