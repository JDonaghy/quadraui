- New `quadraui::interactive` module (#2817): the behaviour half of the
  widget contract — `Interactive`, `RoutedEvent`, `PointerKind`, `KeyEvent`,
  `EventHost`/`EventCx`, `FocusSpec`/`FocusStop`, `interactive::SubTarget`,
  `WidgetAction`/`Never`, and the `non_interactive!` macro. `Interactive` is
  declared `pub trait Interactive: Primitive` — `Self::Layout` is shared
  between the two, so a widget never needs a second, behaviour-only layout
  pass. `interactive::SubTarget` is an opaque per-widget sub-part address
  (a cell, a row, a column), unrelated to the existing
  `primitive::SubTarget` paint-target tag of the same short name. Applied via
  `non_interactive!` to the 6 current `Primitive` impls with no behaviour
  yet (`ListView`, `TreeView`, `DataTable`, `TreeTable`, `CellGrid`,
  `IconGrid`); their real `Interactive` impls land in the widget-contract
  epic's pilot and port issues. The runtime that calls `Interactive::handle`
  is a later issue — nothing in this crate drives the trait yet.
