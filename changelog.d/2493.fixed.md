- `HelpOverlayController`'s `?`-triggered cheatsheet now renders as a
  `Dialog`-backed card — padding, border, `Style::corner_radius` — in the
  chrome/UI font on every backend, instead of a `SidebarPanel` +
  `TextDisplay` composition that painted the body through the (often
  monospace) editor font on GTK/macOS/Win (#2493). Registered actions now
  render in a `DialogTable` ("Shortcut" | "Description") whose column
  widths are auto-sized from each cell's real measured text width, so the
  columns stay aligned under a proportional font instead of a
  fixed-character-count `format!` pad that only lined up on a monospace
  grid.
