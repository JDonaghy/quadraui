- Added an optional `screenshot` MCP tool for an agent that needs to *see*
  the render, not just its accessibility tree (#2721): `Backend::screenshot`
  is a new default-`None` trait method, `quadraui::control`'s
  `ControlRequest::Screenshot`/`ControlHandle::screenshot` route it through
  the control channel, and `quadraui-mcp` lists it as a fifth built-in
  tool alongside `snapshot`/`act`/`key`/`type`. `TuiBackend` is the first
  backend to implement it — same opt-in `crate::frame::set_frame_capture`
  gate as `last_frame` — answering `Screenshot::Text`: one string per
  rendered row plus each row's per-cell style, run-length encoded into
  `ScreenshotRun`s. A backend with no screen to capture (every backend
  without a cell grid or pixel-capture path today) answers a documented
  error, never a panic.
