- A `ContextMenuController` menu and each of its submenus is as wide as
  its widest row (#3044), measured in the chrome font the way an
  application menu's dropdowns already were, instead of a fixed
  20 line-heights. `ContextMenu`'s `Primitive::measure` reports the same
  width. A narrower menu changes where a submenu pulls out, so captures of
  right-click menus shift.
- A menu level's width counts each row's rendered key equivalent
  (`ContextMenuItem::key_equivalent`), not only its `detail`, so a
  right-aligned shortcut no longer overlaps its label in a right-click
  menu or an application menu's dropdown.
