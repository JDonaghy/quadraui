- `RoutedEvent` is `#[non_exhaustive]` (#3028). The runtime's per-widget
  `Interactive::State` lives in a per-thread store reached with
  `with_widget_states`, so `draw_dyn` can paint from it;
  `WidgetRoutingState::states` is removed, and a widget's state is dropped
  as soon as an event's `FrameTree` no longer names it. The binding host
  reports sub-target focus: `EventCx::is_focused(Some(sub))` answers for
  the sub-part a generic leaf last requested focus for.
- `ComboBox`'s dropdown opens through `Interactive::popups` (#3028): it
  paints above every widget in the frame, a press on a row commits it, and
  an outside press or Escape cancels the edit. The box itself is one row
  (`measure` no longer adds a row per match); the list is at most
  `MAX_DROPDOWN_ROWS` tall and scrolls to keep the highlight in view.
  `ComboBox::dropdown_id` names the list for drivers.
