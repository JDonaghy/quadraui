- The GTK backend now services the `quadraui::control` channel (#2717):
  `gtk::run::GtkRunner::attach_control`/`gtk::shell_runner::runner_with_shell`
  mirror the TUI runner's control wiring, draining pending
  `ControlRequest`s once per GLib main-context iteration and routing
  `Act`/`Key`/`Type` through the same `dispatch_event` pipeline real GTK
  input goes through. `GtkBackend` also gains a `last_frame()`/
  `frame_capture()` slot, so a control channel's `snapshot`/`act` can
  build an accessibility tree from a live GTK window the same way it
  already does on TUI.
