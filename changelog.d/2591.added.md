- New `IconGrid` primitive (#2591): a wrapping grid of large icons with a
  label under each (Finder's Icons view / Explorer's Large icons), built on
  the `quadraui::Primitive` seam from #2607 rather than new `Backend`
  methods. `IconGrid::layout` wraps items into as many columns as fit the
  viewport, stacking tile-rows through `primitives::row_stack`'s shared
  arithmetic, and keeps `selected_idx`'s row inside the viewport the same
  way every other row-stacking primitive's layout does. `icon_grid_move_
  selection` resolves Left/Right/Up/Down/Home/End/PageUp/PageDown against
  the resolved column count. TUI paints each tile as a 2-row icon-glyph +
  truncated-label cell, falling back to a single-row `ls`-style tile when
  the rect is too short for two rows; GUI backends paint through a new
  centred icon/label tile painter shared with `ListView`/`Palette`'s
  existing row-content painter (`row_stack::row_content_paint::
  paint_tile_icon_label`). Single selection only today — `IconGridEvent::
  SelectionSet` carries a `Vec<usize>` so a future multi-select extension
  widens it without a breaking change.
