- `FocusTree::sync` now keeps a whole-widget focus address (`(id, None)`)
  focused across a rebuild when the matching id still has *any* stop, not
  only an exact address match — the address `AppLogic::extra_tab_stops`
  always lands on, which a `FocusSpec::Children` widget (`RadioGroup`,
  `CellGrid`, `Dialog`, …) only ever expands into per-child
  `(id, Some(sub))` stops. Without this, tabbing into a `FocusSpec::Children`
  widget lost focus again on the very next routed event.
