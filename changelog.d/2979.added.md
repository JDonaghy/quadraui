- A `schema` feature on `quadraui` (#2979) derives `schemars::JsonSchema`
  on every wire-facing descriptor, `UiEvent` and the types they carry.
  `widget_kinds!` also generates `visit_widget_kinds`, which hands each
  entry's descriptor type to a `KindVisitor` (with `schema` on, every
  entry must implement `JsonSchema`, through `KindSchema`).
  `register_widget_kind_with_schema(kind, decode, schema)` registers a
  runtime kind together with its payload schema, read back with
  `runtime_widget_kind_schema(kind)`. `quadraui-binding-core`'s own
  `schema` feature adds `wire::schema::wire_schema()`, one JSON Schema
  document with `$defs` for every wire type, a `kinds` map from each leaf
  widget kind (static and runtime) to its descriptor and a `roots` map;
  `export_wire_schema` prints it, and any binding can generate its types
  from it.
