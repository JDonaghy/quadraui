- `Primitive::paint_cells` takes `cells: &mut dyn CellSurface` instead of
  a ratatui `Buffer` (#2946), and `PaintTarget::Cells` holds the same
  trait object, so a cell painter reaches the surface's cursor and
  graphics verbs. `quadraui::tui::BufferCellSurface` wraps a bare
  `Buffer` for tests and headless callers; painters that still delegate
  to a ratatui rasteriser reach the buffer through
  `CellSurface::ratatui_buffer`.
