- `CellGrid` now paints on every pixel backend (GTK/macOS/Win) through
  `Primitive::paint` (#2725): column/row headers, gridlines, frozen-pane
  dividers, the rectangular selection fill, the cursor ring and styled
  cell text (per-cell bold/italic/underline/foreground/background via
  `CellStyle`), reusing `DataTable`'s ellipsis/alignment text-fitting
  helper rather than forking it. `CellGrid` also gets a real
  `A11yPrimitive` impl: a `Table` role with a column-header `Row`, one
  `Row` per visible sheet row (an optional row-header `Cell` plus one
  `Cell` per visible column, each carrying its text and `selected` state
  for the resolved selection rectangle), and `a11y_focus_key` naming the
  cursor cell.
