- `PasswordInput` drops a line break from pasted or IME-committed text
  instead of splitting its one-line value.
- A `Form` text row keeps its undo history while it holds focus, so
  Ctrl/Cmd+Z undoes past the last keystroke. `form::TextCursor` gains a
  `history: EditHistory` field for it; code that builds a `TextCursor`
  literal adds `history: EditHistory::default()`.
