- A single-line `TextInput`/`PasswordInput` — standalone or a `Form` row —
  now sizes its box from `Style::control_height` (26px) instead of a
  backend's own line-height measurement (#2489): a new
  `text_input::TextInputMetrics::resolve` resolves the box height
  straight from `Style`, and `Form`'s `FieldKind::TextInput`/
  `PasswordInput` rows floor at `control_height + 4.0` so the stroked box
  `native_surface_paint::paint_text_input_box` draws actually reaches
  26px on every GUI pixel backend (GTK/macOS/Win); TUI (cell-quantised,
  no sub-cell height to refine) is unaffected.
