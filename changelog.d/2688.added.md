- A `"grid"` layout-tree node kind for the bindings (#2688):
  `quadraui-binding-core`'s `LayoutNode::Grid`/`LayoutGrid` decode two
  independent `columns`/`rows` track lists (`quadraui::layout::GridTrack`:
  `Fixed`/`Percent`/`Weight`/`Content`) plus a row-major `cells` list, and
  paint through `quadraui::layout::resolve_grid_tracks`, so a Python/
  TypeScript render callback can return a two-dimensional dashboard as one
  node instead of a hand-nested row of columns. `quadraui-py`'s
  `wire.pyi` and `quadraui-node`'s `wire.d.ts` carry the generated
  `GridTrack`/`LayoutGridPayload`/`LayoutGridNode` types. Ships with the
  `tui_grid`/`gtk_grid` example pair and its `TuiDriver` acceptance test.
