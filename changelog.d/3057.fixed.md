- While the menu is closed, a pointer event on the menu-bar strip outside a
  label — including the band past the last label — returns
  `MenuEvent::Ignored` again (#3057), so it reaches the host's own chrome
  (a command center, window controls). A move there still clears the label
  hover; the new `MenuSystem::view_changed()` reports that the call changed
  what the menu paints, so a host that repaints only on a handled event
  still repaints the bar.
- An in-window `MenuBar` always underlines a label's `&` mnemonic (#3057),
  chosen by the menu style rather than the host OS, so GTK on macOS
  underlines `&File`. The macOS-only painter without mnemonics is removed.
