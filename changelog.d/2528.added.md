  family-agnostic hover/pressed/focus derivations a per-node style
  override's state-variant branch (`quadraui-binding-core`'s
  `StyleOverride::resolve`) falls back to for a leaf with no

  existing field (`list_hover_bg`/`list_pressed_bg`/`accent_fg`), so no
  new `Theme` field is added and every existing exhaustive palette
  literal keeps compiling unchanged.

  shape both bindings decode through `quadraui-binding-core`'s
