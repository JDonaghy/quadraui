- `Form`'s `FieldKind::Button` and `FieldKind::Dropdown` now paint through
  the shared `button` chrome / a stroked box instead of text runs (#2488):
  a standalone `Button` field painted its caption as `<label>` bracket
  glyphs with no fill, border or `Style::button_radius` corner, and a
  `Dropdown` field painted its chosen option as bare text next to a
  floating chevron with no box around either. Both now read as real
  controls on every GUI pixel backend (GTK/macOS/Win); the TUI painter,
  which has no fill/stroke affordance, is unaffected.
