- `gtk::run`/`gtk::run_with`/`gtk::shell_runner::run_with_shell` now return
  `Result<(), quadraui::RunError>` instead of `std::process::ExitCode`/`()`
  (#2836): the shared `RunError` seam (#2834) every backend's `run`/
  `run_with` converges on. A caller's `fn main` that previously ended in
  `quadraui::gtk::run(app)` with a `-> std::process::ExitCode` signature
  changes that signature to `-> Result<(), quadraui::RunError>` (or, to
  keep `ExitCode` ergonomics, matches on the result and calls
  `RunError::report`); a `run_with_shell(app, config)` caller that
  previously ignored the return value should now propagate or match it
  instead, since the call now reports the same GLib-exit-code/headless-
  smoke failures `run`/`run_with` already did instead of silently
  discarding them.
