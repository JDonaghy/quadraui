- `quadraui::NaturalSize` and `quadraui-binding-core`'s
  `ExtraPaint::natural_size` (#2524): every additive leaf kind — `Checkbox`,
  `Switch`, `ProgressBar`, `Image`, `RadioGroup`, `Slider`, `Select`,
  `ComboBox`, `TextInput`, `TextField`, `PasswordInput`, `TextArea`,
  `Spinner`, and more — can now report its own best-effort intrinsic
  `(width, height)`, consulted by a `Row`/`Column` layout tree's
  non-`Stretch` `crate::layout::Align` so `Align::Start`/`Center`/`End`
  sizes these leaves to their own content instead of always degrading to
  the full cross-axis extent, the same treatment `Button`/`TextDisplay`/
  `TabBar` already had. Defaults to `NaturalSize::NONE` (no cheap
  measurement, degrade to `Stretch`), so every extra kind that doesn't
  override it renders exactly as before.
