- macOS `TabBar` rasterisation now goes through the shared
  `primitives::tab_bar::native_surface_paint::paint` and
  `primitives::layout_metrics::pixel_tab_bar_layout_fitting_boundary`
  instead of macOS-only layout/paint code (#2503): `macos::tab_bar::mac_tab_bar_layout`,
  `mac_tab_bar_layout_icons`, `mac_tab_bar_native_layout`, and
  `mac_tab_bar_native_layout_icons` are removed in favour of the new
  `macos::tab_bar::mac_tab_bar_pixel_layout`. This also adopts the shared
  painter's close-button convention on macOS: the close hit region is now
  flush with the tab's trailing edge (`tab_inner_gap + glyph` wide) rather
  than the old bespoke leading-gap box, and a hovered close glyph now
  paints a rounded hover backdrop macOS previously left unpainted.
