- `LayoutCtx` carries the widget's paint state (`LayoutCtx::with_paint_state`
  / `paint_state`), so `Primitive::layout` resolves the same `scroll_px` the
  painters use (#3068). `draw_dyn` attaches the caller's state to its layout
  passes and records an owned `PaintStateSnapshot` in the new
  `PaintedWidget::paint_state` field; event routing lays the widget out
  again against that record (`primitive::painted_state`). `TreeTable::
  layout_scrolled` lays a tree table out at a pixel scroll position.
- `ListView::striped` (wire key `striped`, default `false`) paints
  alternating row stripes from the descriptor itself, the way
  `DataTable::striped` does; `PaintState::striped` still turns them on per
  paint (#3068).
