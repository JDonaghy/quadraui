- `TextDisplayLine::plain(text)`: one unstyled line (a single
  `StyledSpan::plain` span, no decoration, no timestamp). The Python and
  Node app layers gain `App.quit()`, default quit keys (Ctrl-C, and `q`/Esc
  when unconsumed), an optional `App` size, a `Text` node (`<text>` in
  JSX), and per-child `size`/`min`/`max` on every node; see
  `quadraui-py/CHANGELOG.md` and `quadraui-node/CHANGELOG.md` (#3107).
