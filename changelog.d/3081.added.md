- The `quadraui` Python package now ships a GTK-enabled Linux wheel
  (#3081): on glibc 2.39+ hosts (Ubuntu 24.04+, Fedora 40+, Debian 13+)
  `pip install quadraui` gives a working `QuiApp.run_native()` GTK window
  when the system GTK 4 (4.10+) runtime is installed, linking the system
  libraries rather than vendoring them. Without GTK, `import quadraui` and
  `run_tui()` still work and `run_native()` raises `UnsupportedError`
  naming `libgtk-4.so.1` and the per-distro install command. Older-glibc
  hosts keep the TUI-only `manylinux_2_17` wheel. See
  `quadraui/docs/INSTALL.md`.
