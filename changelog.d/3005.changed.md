- **Breaking:** `ButtonLayout` gains a required `nerd_fonts_enabled` field
  (#3005), carried from `LayoutCtx` at layout time so `paint_cells` (which
  takes no `LayoutCtx` of its own) still knows whether to paint a Nerd Font
  icon glyph or its ASCII fallback — the same information
  `TabBarPrimitiveLayout::nerd_fonts_enabled` and
  `ActivityBarPrimitiveLayout::nerd_fonts` already carry for the same
  reason. `Button::layout` and every `Backend::{draw_button,
  draw_button_with_state, button_layout}` impl set it to `false`, so code
  that only *reads* a returned `ButtonLayout` is unaffected; code that
  builds one with a struct literal must add the field.
