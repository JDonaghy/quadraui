- `MacBackend`'s `MultiSectionView` rasteriser no longer paints a redundant
  8px scrollbar-shaped gutter column beside a `Tree` section's own 10px
  overlay scrollbar (#2495): an overflowing `Tree` section's body already
  paints its own vertical scrollbar via the shared tree painter, so the
  MSV's own gutter column — previously painted unconditionally whenever
  the section's content overflowed — now stays plain background whenever
  the body already paints one of its own, leaving a single scrollbar
  column instead of two adjacent shaded strips.
