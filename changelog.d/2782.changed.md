- `FormEvent` is now `#[non_exhaustive]` (#2782): a downstream `match` on
  `quadraui::FormEvent` must add a wildcard arm (`_ => {}`) to keep
  compiling. Construction (`FormEvent::ButtonClicked { id }`) and
  single-variant destructuring (`if let FormEvent::FocusChanged { id } =
  ev`) are unaffected. This closes off a future variant (e.g. a new field
  kind's own event) from being a breaking change on its own.
  In-repo blast radius: every exhaustive `FormEvent` match inside
  `quadraui/src` and `quadraui/tests` needed no change (non_exhaustive
  doesn't constrain the defining crate's own matches). The one exhaustive
  match living outside the defining crate, `quadraui-binding-core`'s
  `wire_schema.rs` coverage guard, now has a wildcard arm plus the same
  `variant_shape_test!` runtime probe
  (`form_event_variants_match_the_schema_tag_list`) that `Key`/`MouseButton`
  established, since that enum's own exhaustive match lives outside the
  defining crate. Grepping `vimcode` and `coord-tui` found every exhaustive
  `FormEvent` match already falls through a final wildcard/catch-all arm,
  so neither needs a migration.
