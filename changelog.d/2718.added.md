- The macOS backend now services the `quadraui::control` channel (#2718):
  `macos::run::MacRunner::attach_control`/`macos::shell_runner::runner_with_shell`
  mirror the TUI/GTK runners' control wiring, draining pending
  `ControlRequest`s once per `step`/`pump` iteration and routing
  `Act`/`Key`/`Type` through the same `dispatch_event` pipeline real macOS
  input goes through. `MacBackend` also gains a `last_frame()`/
  `frame_capture()` slot, so a control channel's `snapshot`/`act` can
  build an accessibility tree from a live macOS window the same way it
  already does on TUI/GTK.
