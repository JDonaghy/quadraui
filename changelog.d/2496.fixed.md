- A `Form`'s `ToggleGroup`/`ButtonRow`/`SegmentedControl`/`Toolbar` field now
  aligns its control to the same shared `LabelPosition::Left` label column
  every other field kind's control already starts at, instead of reserving
  only its own (often much narrower) label's width (#2496): `FormFieldMeasure`
  gains a `label_w` field and `FormLayout` gains a `left_label_width` field,
  `Form::layout` widens an item-bearing row's `items_start_x` to the shared
  column, and `MacBackend::draw_form`'s embedded `Toolbar` rasteriser reads
  that same column instead of re-measuring just the field's own label — so
  these rows no longer crowd into the span a wider-labelled sibling row
  reserves for its own label.
