- A `Form`'s `ToggleGroup`/`ButtonRow`/`SegmentedControl`/`Toolbar` field now
  starts its control at the same shared `LabelPosition::Left` label column
  every other field kind's control already starts near, instead of reserving
  only its own (often much narrower) label's width (#2496): `FormFieldMeasure`
  gains a `label_w` field and `FormLayout` gains a `left_label_width` field
  and a `toolbar_field_rect` method, `Form::layout` widens an item-bearing
  row's `items_start_x` to the shared column, and every embedded-`Toolbar`
  rasteriser (`GtkBackend`/`MacBackend`'s `draw_form`, both
  `MultiSectionView` form bodies) calls `toolbar_field_rect` for that same
  column instead of re-measuring just the field's own label — so these rows
  no longer crowd into the span a wider-labelled sibling row reserves for
  its own label, and the painted toolbar always lines up with where clicks
  are routed.
