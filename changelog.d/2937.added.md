- `ListView` now implements `Interactive` for real (#2937): keyboard
  navigation (arrows/`j`/`k`, Home/End, Page Up/Down, Enter, Ctrl+A) and
  mouse click/double-click over rows, routed through the generic
  `Interactive`/`RoutedEvent` runtime instead of `non_interactive!`. A new
  `ListViewState` (`Interactive::State`) tracks the multi-selection set
  and its range-extension anchor; `ListViewEvent` gains an
  `impl WidgetAction` so a routed event turns into `UiEvent::List`
  automatically. `ListView` also gains `Primitive::id`/`Primitive::capture`
  overrides, so it round-trips through `Surface::Widget`/`OwnedFrame`
  the same way every other `Interactive` primitive does. `widget_kinds!`
  gains a `"list" => ListView` entry alongside `cell_grid`/`icon_grid`.
  `grep -rn 'ListViewEvent\|ListViewState' ~/src/coord-tui/src
  ~/src/vimcode/src` finds no hits, so this has zero downstream blast
  radius.
