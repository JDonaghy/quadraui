- `Palette` is on the widget contract (#2874): it implements `Primitive`
  (`PalettePrimitiveLayout`, with layout, pixel paint and cell paint all in
  `primitives::palette`) and `Interactive` (`PaletteState`, emitting the
  existing `PaletteEvent` as its `Action`), so a command palette paints and
  routes through `Surface::Widget`/`DrawsPrimitives::draw_dyn` with no
  `Backend::draw_palette`/`palette_layout` call. Keyboard: the query row
  edits through the shared flat-value editing core (printable keys,
  Backspace/Delete, Left/Right, Home/End, Ctrl-A/C/X) while Up/Down and
  PageUp/PageDown move the item highlight; Enter confirms the highlighted
  row and Escape dismisses. A single click selects the row under the
  pointer, a double-click confirms it, and every other press inside the
  popup is swallowed so a modal overlay never leaks a click to the UI it
  covers.
