- The editor's `Style::font_scale` is honoured again by every pixel
  backend (#3037): `TextRunStyle` gains a `scale` field and
  `with_scale(f32)` builder (default 1.0), and every `PaintSurface`
  text-line verb applies it — GTK as a Pango scale attribute, macOS as a
  Core Text font at the scaled size, Win as a DirectWrite font-size range,
  the monospace default as a scaled advance. The shared editor pixel
  painter passes each span's `font_scale` through, grows the line's text
  box to its tallest run, and measures caret, selection, span background
  and underline positions with the run attributes (weight, slant, scale)
  applied. **Breaking:** `PaintSurface::surface_text_x_at_index` and
  `surface_text_index_at_x` take the line's `runs: &[TextRunStyle]` after
  `text`; pass `&[]` for the unstyled advance. The TUI cell painter is
  unchanged: a scaled span still paints one cell per character.
