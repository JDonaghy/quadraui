- TUI's `TabBar` rasteriser (`tui::tab_bar`) now builds its returned
  `TabBarHits` via the shared `backend::tab_bar_hits_from_layout` +
  `backend::shift_tab_bar_hits` helpers — the same pair
  `TuiBackend::tab_bar_layout_icons`'s no-paint twin already uses — instead

  `tui::tab_bar` test, including the close-glyph, bracket-framing, icon
  reservation, and reverse-video focus tests, passes unchanged.

  ## Downstream impact
