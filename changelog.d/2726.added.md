- `CellGrid::cells_window` and `CellGrid::cells_requested` — two-axis
  virtualisation for the spreadsheet-style `CellGrid` primitive: the former
  reports the absolute sheet block the scrolled (non-frozen) portion of
  `CellGrid::cells` currently covers; the latter compares that window
  against a resolved `CellGridLayout` and returns a new
  `CellGridEvent::CellsRequested { row_start, col_start, rows, cols }` when
  the loaded block no longer covers the viewport, so a host can supply only
  the visible slab of a sheet with millions of rows and tens of thousands
  of columns (#2726).
