- `macos::run`/`macos::run_with`/`macos::shell_runner::run_with_shell` now
  return `Result<(), quadraui::RunError>` instead of
  `std::process::ExitCode` (#2837): the shared `RunError` seam (#2834)
  every backend's `run`/`run_with` converges on, mirroring the TUI (#2835)
  and GTK (#2836) migrations. A caller's `fn main` that previously ended
  in `quadraui::macos::run(app)` with a `-> std::process::ExitCode`
  signature changes that signature to `-> Result<(), quadraui::RunError>`
  (or, to keep `ExitCode` ergonomics, matches on the result and calls
  `RunError::report`); a `run_with_shell(app, config)` caller that
  previously ignored the return value should now propagate or match it
  instead.
