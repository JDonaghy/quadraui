- `quadraui::Placed<W>` (#3055): a widget paired with a layout its host
  already resolved. `Placed::layout` returns the held layout whatever rect
  it is given, and paint, bleed, focus, sub-regions, event handling, popups
  and accessibility are the wrapped widget's own, so a host that flips a
  tooltip, sizes a dialog itself or places a completion list paints and
  hit-tests at its own placement through `draw_dyn`.
