- New standalone `TextField` primitive (#2590): a single-line framed
  text field with an optional leading `Icon` (e.g. a search magnifier)
  and an optional clear (×) button, placeable anywhere rather than only
  as a `Form` row. `TextField::layout` scrolls horizontally so the
  cursor always stays visible, and drops the clear button first, then
  the icon, under width pressure. Editing goes through the existing
  `EditOp`/`TextEditor` machinery via the new
  `primitives::text_input::apply_flat_edit_op` bridge, now shared with
  `FormController`'s `FieldKind::TextInput`/`TextArea`/`PasswordInput`
  handling. TUI paints the real one-row `[ icon value × ]` rasteriser
  (`Backend::draw_text_field`'s override on `TuiBackend`); GTK/macOS/Win
  take `Backend::draw_text_field`'s default fallback (a plain bordered
  box via `draw_text_input`, no icon or clear button yet) until a
  tracked follow-up gives each GUI backend its own dedicated painter.
