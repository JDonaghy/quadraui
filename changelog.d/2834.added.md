- `RunError` (#2834): the unified `std::error::Error` +
  `std::process::Termination` return type every backend's `run`/
  `run_with` will converge on, replacing today's split between
  `tui::run`'s `std::io::Result<()>` and `gtk::run`/`macos::run`/
  `win::run`'s bare `std::process::ExitCode`. This change only adds the
  type (`quadraui::RunError`); no backend's `run`/`run_with` signature
  changes yet. A later per-backend issue switching one of those
  functions to return `Result<(), RunError>` **will be a breaking
  change** for that backend's callers.
