- `tui::run`/`tui::run_with`/`tui::shell_runner::run_with_shell` now return
  `Result<(), quadraui::RunError>` instead of `io::Result<()>`/`()` (#2835):
  the shared `RunError` seam (#2834) every backend's `run`/`run_with`
  converges on. A caller's `fn main` that previously ended in
  `quadraui::tui::run(app)` with a `-> std::io::Result<()>` signature
  changes that signature to `-> Result<(), quadraui::RunError>`; a
  `run_with_shell(app, config)` caller that previously ignored the return
  value should now propagate or match it instead, since the call now
  reports the same terminal-setup/teardown failures `run`/`run_with`
  already did instead of silently discarding them.
