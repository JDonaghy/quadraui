- `Canvas` gains named, hit-testable `regions` (`CanvasRegion { id, rect, cursor }`)
  and a `focusable` flag (#2664), both additive via `#[serde(default)]`.
  `CanvasLayout::region_hit_test` resolves a click/hover to
  `CanvasHit::Region { id }` (now `#[non_exhaustive]`) on every backend, and
  TUI additionally ships `tui_canvas_region_hit_test` in `quadraui::tui`, a
  cell-quantised variant using the same floor/ceil-outward rounding
  `CellClip::push` already uses for `PushClip`.
