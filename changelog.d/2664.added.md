- `Canvas` gains named, hit-testable `regions` (`CanvasRegion { id, rect, cursor }`)
  and a `focusable` flag (#2664), both additive via `#[serde(default)]` on the
  wire (a JSON/binding `CanvasDescriptor` written before this change still
  decodes). A Rust `Canvas { .. }` or `CanvasHit` literal is not additive: the
  two new struct fields must now be listed at every construction site, and
  `CanvasHit` gaining `#[non_exhaustive]` breaks an exhaustive downstream
  `match` — no in-tree or published consumer hits this today (zero `Canvas`/
  `CanvasHit` references in vimcode or coord-tui).
  `CanvasLayout::region_hit_test` resolves a click/hover to
  `CanvasHit::Region { id }` (now `#[non_exhaustive]`) on every backend, and
  TUI additionally ships `tui_canvas_region_hit_test` in `quadraui::tui`, a
  cell-quantised variant using the same floor/ceil-outward rounding
  `CellClip::push` already uses for `PushClip`.
