- **Breaking:** `Surface::TabBar` is removed (#2985) — push a tab bar as
  `Surface::Widget { rect, widget: Box::new(tab_bar) }` instead, which
  paints through `DrawsPrimitives::draw_dyn` and routes clicks/keys
  through `TabBar`'s own `Interactive` impl via
  `ScreenLayout::into_frame_tree`. The variant's `hovered_close` field has
  no replacement: `Primitive::paint` takes no paint-time state, so a
  hovered close glyph is not expressible through the widget contract yet.
  `OwnedContent::TabBar` is now the capture of a `TabBar` reached through
  `Surface::Widget` (it maps to `FrameZone::Widget`, not
  `FrameZone::TabBar`), replacing the separate `OwnedContent::TabBarWidget`
  variant. `FrameZone::TabBar` still exists but is no longer produced by
  any `ScreenLayout`/`OwnedFrame`.
