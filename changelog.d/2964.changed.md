- `Image` is on the widget contract (#2964): it implements `Primitive`
  (`non_interactive!`), so a `Surface::Widget` image paints through the
  same path as every other contract widget. `Primitive::paint` hands the
  source to `PaintSurface::surface_draw_image`, which now holds each pixel
  backend's decode-and-paint (Win gains the decode cache GTK and macOS
  already had); `Primitive::paint_cells` asks
  `CellSurface::emit_graphics` first — Kitty graphics or the half-block
  mosaic on TUI under `tui-images` — and paints `fallback_text` itself
  when the channel paints nothing. `Primitive::measure` reports the
  fallback text's width by one row on a cell grid and `intrinsic_size` on
  a pixel surface. **Breaking:** `ImageLayout` gains a public `area`
  field, the rect the image was fitted within.
