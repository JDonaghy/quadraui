- `DataTablePaintState`/`ListPaintState` gain a `striped` flag (#2448),
  set via `with_striped(true)`, that tints every other non-selected,
  non-header body row with the new `Theme::row_alt_bg` accessor
  ("zebra striping") — opt-in, default `false`; selection and hover
  highlights still paint on top of the stripe. Honoured on every
  backend (TUI, GTK, macOS, Win32) for both `DataTable` and
  `ListView`. A terminal quantised to `ColorDepth::Ansi16` rounds the
  stripe back to the row's own colour, dropping it automatically on
  low-colour terminals.
