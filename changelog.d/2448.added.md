- `DataTablePaintState`/`ListPaintState` gain a `striped` flag (#2448),
  set via `with_striped(true)`, that tints every other non-selected,
  non-header body row with the new `Theme::row_alt_bg` accessor
  ("zebra striping") — opt-in, default `false`; selection and hover
  highlights still paint on top of the stripe. Honoured on TUI and GTK
  for both `DataTable` and `ListView`; macOS and Windows forward the
  paint-state struct unchanged into the shared painters that already
  read it for `DataTable`, but their own `ListView` entry points don't
  thread the flag through yet. A terminal quantised to
  `ColorDepth::Ansi16` rounds the stripe back to the row's own colour,
  dropping it automatically on low-colour terminals.
