- `DataTablePaintState`/`ListPaintState` gain a `striped` flag (#2448),
  set via `with_striped(true)`, that tints every other non-selected,
  non-header body row with the new `Theme::row_alt_bg` accessor
  ("zebra striping") — opt-in, default `false`; selection and hover
  highlights still paint on top of the stripe. `DataTable` striping is
  honoured on every backend (TUI and GTK directly; macOS and Windows
  forward `DataTablePaintState` unchanged into the shared painter that
  already reads it). `ListView` striping is honoured on TUI; the shared
  GTK/macOS/Windows list painter also accepts the flag, but none of
  those backends' own entry points thread it through yet. A terminal
  quantised to `ColorDepth::Ansi16` rounds the stripe back to the row's
  own colour, dropping it automatically on low-colour terminals.
