- `TreeController`'s selection/navigation state (selected path, scroll
  offset, pixel scroll position, scrollbar drag) now lives in a new
  row-agnostic `compose::tree_nav::TreeNavCore`, driven through a small
  `NavRow` trait (`path`/`indent`/`is_expanded`) that `TreeRow` implements
  (#2604). `TreeNavCore` also exposes a generic Left/Right rule (collapse
  else select parent / expand else select first child) for a future
  TreeTable row controller to reuse; `TreeController` itself keeps its
  existing public API and behavior unchanged — it does not call the new
  Left/Right method, since it has none today.
