- `board_layout` is renamed `measured_board_layout`, and
  `multi_section_view::{msv_layout, msv_metrics}` are renamed
  `pixel_msv_layout`/`pixel_msv_metrics` (#2975).
- On GTK a `MessageList` paints every row through the shared per-span
  painter, the same one macOS and Windows use, so markdown heading rows
  no longer scale on GTK (#2975).
- The bindings place a `"canvas"` leaf on the generic widget leaf
  (`WIDGET_KINDS`) instead of the `ExtraPaint` table (#2975): the canvas's
  own `Interactive` resolves its region clicks, double-clicks and hover,
  and a hover over a canvas reports the generic `MouseEntered`/`MouseLeft`
  with `hit: {"kind": "widget_body"}` rather than `"canvas_region"`. Every
  generic leaf now gets the native runtime's hover tracking in the
  bindings: entering a leaf routes it an `Enter` and leaving routes a
  `Leave`, so a `Canvas` reports `RegionHovered` and a `Chart` reports
  `DataPointHovered` from Python and Node as they do natively. As on the
  native runtime, a move that stays within one widget does not reach it.
