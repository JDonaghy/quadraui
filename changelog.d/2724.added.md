- `CellGrid` TUI painter (#2724): `crate::tui::draw_cell_grid` /
  `tui_cell_grid_layout` paint the column-letter header strip, the
  row-number gutter, cell text clipped to column width with an ellipsis,
  frozen-pane dividers, the cursor cell highlighted, the selection range
  tinted, and `CellStyle` mapped onto terminal bold/italic/underline and
  colour. Wired through `crate::primitive::Primitive` (no bespoke
  `Backend::draw_cell_grid` method) and a new `Surface::CellGrid` /
  `FrameZone::CellGrid` pair, so a `CellGrid` composes into a
  `ScreenLayout`-assembled screen the same way every other primitive
  does. GTK/macOS/Win get their own `CellGrid` rasteriser in a follow-up
  issue; `CellGrid::paint` is a no-op on those backends until then.
