- `FocusTree::restrict` (#2910) narrows this frame's tab order down to
  the stops a predicate keeps, clearing focus if the currently-focused
  stop is dropped — the primitive a host uses to trap Tab/Shift+Tab
  cycling inside an open modal (by id, or by containment against its
  `ModalStack` bounds) instead of letting it escape to a base-layer
  stop hidden behind it. `FocusTree::sync_tab_order` is now `pub`
  (previously crate-private), for a host managing a `FocusTree`
  directly from a flat `(WidgetId, Rect)` list with no `FrameTree`.
