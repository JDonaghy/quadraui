- `ListView` now implements `Interactive` for real (#2938): arrow keys,
  vim `j`/`k`, Home/End, and Page Up/Down move `selected_idx` and report
  it via `ListViewEvent::SelectionChanged`; Enter activates the current
  selection as `ItemActivated`; a left click on a row selects it and
  requests focus — routed through the generic `Interactive`/`RoutedEvent`
  runtime instead of `non_interactive!`. An unhandled key still falls
  through to `ListViewEvent::KeyPressed`, matching the primitive's
  existing documented contract.
