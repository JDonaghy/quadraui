- `CellGrid` primitive (#2723): descriptor, layout and hit-testing for a
  spreadsheet-style grid of cells, with no paint path yet. Column headers
  default to spreadsheet letters (`A`…`Z`, `AA`…) via the new
  `column_letters`, row headers to 1-based row numbers, both overridable
  per-index and hideable independently. Leading rows/columns can be frozen
  — `CellGrid::layout` resolves them first, in a fixed position, followed
  by the scrolled body — and `CellGridLayout::hit_test` maps a click to
  `CellGridHit::Corner`/`ColumnHeader`/`RowHeader`/`Cell`/`VScrollbar`/
  `HScrollbar`. `CellStyle::align`'s `CellAlign::General` right-aligns
  text that looks like an already-formatted number (`"$1,200.50"`,
  `"(42)"`, `"42%"`) and left-aligns everything else, reusing
  `DataTable`'s `ColumnAlign` rather than forking a parallel enum.
