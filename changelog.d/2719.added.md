- The Win-GUI backend now services the `quadraui::control` channel (#2719):
  `win::run::WinRunner::attach_control`/`win::shell_runner::runner_with_shell`
  mirror the TUI/GTK/macOS runners' control wiring, draining pending
  `ControlRequest`s once per `step`/`pump` iteration and routing
  `Act`/`Key`/`Type` through the same `dispatch_event` pipeline real Win32
  input goes through. `WinBackend` also gains a `last_frame()`/
  `frame_capture()` slot, so a control channel's `snapshot`/`act` can
  build an accessibility tree from a live Win-GUI window the same way it
  already does on TUI/GTK/macOS.
