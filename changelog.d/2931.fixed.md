- macOS: a native menu item's `Reaction` (e.g. `Reaction::Exit` from File >
  Quit) is no longer silently discarded (#2931). `macos::run`'s `paint`
  closure drained native-menu-activation `UiEvent`s from inside `drawRect:`
  but threw away each `AppLogic::handle` call's `Reaction`; now it folds
  them via `Reaction::merge` and hands the result back to `draw_rect`,
  which applies it once painting has finished. An `Exit` defers to a
  zero-delay, one-shot `NSTimer` (`QuadraView::apply_paint_reaction`)
  rather than calling `[NSApp terminate:]` while still inside `drawRect:`;
  `Redraw`/`RedrawAfter` apply immediately, same as any other event.
