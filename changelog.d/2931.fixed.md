- macOS: a native menu item's `Reaction` (e.g. `Reaction::Exit` from File >
  Quit) is no longer silently discarded (#2931). Events queued from
  non-responder sources — native menu and tray activations,
  `Backend::waker` payloads, notification activations — are drained through
  `QuadraView::dispatch_queued_events`, which routes each one into the same
  `QuadraView::dispatch` path every responder event takes, so its
  `Reaction` is applied (`Exit` → `[NSApp terminate:]`, `Redraw` →
  `setNeedsDisplay`, `RedrawAfter` → a backend timer). The drain runs from
  the wake callback the menu/tray action selectors invoke and from the
  `idlePollTick:` backstop, mirroring GTK's `drain_and_tick`, instead of
  from inside `drawRect:`. The `macos_native_menu` example gains a
  File > Quit Demo item that exercises the `Exit` case.
