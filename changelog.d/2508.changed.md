- Windows's `Spinner` rasteriser (`win::spinner`) now paints through the
  shared `primitives::spinner::native_surface_paint::paint` instead of its
  own `FRAMES`/`frame_text`/`draw_spinner` copy; `WinBackend::draw_spinner`
  calls the shared painter directly (`self` is the `PaintSurface`), the
  same shape `WinBackend::draw_progress` already uses (#2508). `win::panel`
  and `win::activity_bar` were already reduced to this shape in an earlier
  pass. No behaviour change: `win::spinner`'s own test suite, rewritten to
  paint through the shared painter, still asserts the same contract
  (layout/hit-test round trip, no-panic paint, accent override, live-theme
  foreground). The now-unused `pub use spinner::draw_spinner` re-export in
  `win::mod` is dropped; it had zero in-tree or downstream (`coord-tui`,
  `vimcode`) callers.
