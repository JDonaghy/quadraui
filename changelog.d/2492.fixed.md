- `Palette` item rows (and the pinned create-action row) now pitch at the
  `Style::row_height` list/tree token (22px) on a pixel backend instead of
  the raw chrome line height, matching `List`/`TreeView`'s own row pitch
  (#2492): `native_surface_paint::layout` floors each row at `22.0`, same
  as `GtkBackend::resolved_row_height`'s rationale. The selected row's `▶`
  text marker is also dropped — the selection highlight
  (`Theme::selected_bg`) alone now conveys which row is selected, on
  GTK/macOS/Win; TUI's own cell-grid palette renderer is unaffected.
