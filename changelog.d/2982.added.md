- `quadraui::route_widget_action` is public (#2982): a host routes an
  assistive-technology action to a live `Surface::Widget`'s
  `Interactive::handle`, the same path its mouse and keyboard input take,
  for a widget defined inside or outside the crate.
- CI pins the widget contract at its final values (#2982): every widget
  kind implements both `Primitive` and `Interactive`
  (`tests/widget_contract_coverage.rs`); a widget defined outside the crate
  lays out, paints in cells and pixels, takes focus, and handles keys,
  clicks and accessibility actions through public API
  (`tests/primitive_public_api.rs`), and is reachable by kind name through
  binding-core's runtime registry
  (`quadraui-binding-core/tests/out_of_crate_widget.rs`); and a deny-list
  (`tests/duplicate_symbols_deny_list.rs`) fails if a deleted duplicate
  symbol, a widget-shaped `Backend` method or a per-backend widget file
  comes back.
