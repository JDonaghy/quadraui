- A Rust app layer, `quadraui::app` (#3106), in the same model-view-update
  shape as the Python and Node app layers: implement `View` (`view(&self)
  -> Node<Msg>`, `update(&mut self, Msg) -> Command`, optional `on_event`
  and `quits_on`), build the tree with `column`/`row` and the leaf
  constructors `text` (sized to its lines by default, like Python's
  `Text` and Node's `<text>`), `button`, `list`, `form` + `text_field`,
  `status_bar` and `widget` (any widget implementing the new `Leaf`
  trait), give each child its own `size`/`fixed`/`content`/`weight`/
  `percent`/`min`/`max` and each container its `gap`/`padding`/`justify`/
  `align`, and run it with `run_tui(app)` or `run_native(app)`. `Run<V>`
  is the `AppLogic` adapter underneath (for test drivers and the
  per-backend runners): it builds the view once per frame, lays it out
  through the core stack solver, paints it, routes against the kept
  frame, and keeps an uncontrolled `Form`'s focused field. `q` and Escape
  quit by default unless the focused widget takes the key, and Ctrl-C
  unless a focused text field takes it. Everything is in
  `quadraui::prelude`. The README hero and the parity app's Rust versions
  are rewritten on it.
