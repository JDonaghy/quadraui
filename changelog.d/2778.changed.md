- `Key` is now `#[non_exhaustive]` (#2778): a downstream `match` on
  `quadraui::Key` must add a wildcard arm (`_ => {}`) to keep compiling.
  Construction (`Key::Char('x')`, `Key::Named(NamedKey::Enter)`) and
  single-variant destructuring (`if let Key::Char(c) = key`) are
  unaffected. Unlike `UiEvent` (#2777), this one has real downstream hits:
  `vimcode`'s `render::engine_key_from_ui` (`render/key_decode.rs`) and
  `App::handle_dispatch`'s key decode (`app/dispatch.rs`) both match `Key`
  exhaustively over just `Char`/`Named` with no wildcard arm today, so
  they need one added at `vimcode`'s next deliberate `quadraui` version
  bump. `coord-tui`'s key-handling matches were all found to already
  fall through a final `_`/unmatched-key arm, so it needs no migration.
