- `TreeTable` now paints on GTK, macOS and Win-GUI (#2598): the three
  backends' `Backend::draw_tree_table`/`tree_table_layout` forward to a new
  shared `primitives::tree_table::native_surface_paint` module — the same
  `DataTable` header/body/scrollbar/footer skeleton with column 0 painted
  as a tree cell (indent, chevron, icon) via the existing `TreeView` tree-
  cell painter — instead of falling back to a plain `DataTable` render
  with no chevrons.
- `quadraui-binding-core` wires `TreeTable` through to Python/Node: a click
  on a branch row's chevron now resolves to a typed `UiEvent::TreeTable(id,
  TreeTableEvent::ToggleExpanded { .. })` instead of only a raw
  `MouseDown`, via a new `HitDetail::TreeTableChevron` hit kind.
