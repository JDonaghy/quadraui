- `Dialog::measure_generic_with_style` and
  `Dialog::measure_generic_measured_with_style` (#2490): like
  `measure_generic`/`measure_generic_measured`, but on a pixel backend
  (`line_height > 1.0`) size `DialogMeasure::button_row_height` from
  `Style::control_height` instead of the raw chrome line height —
  matching the fixed-pixel button row `MessageDialogController::layout`
  already renders its OK/Cancel row at. TUI's char-grid geometry
  (`line_height == 1.0`) is unchanged. The button row's corner radius
  (`Style::button_radius`) is unaffected — `native_surface_paint::paint`
  already resolves it via `ButtonMetrics::resolve`.
