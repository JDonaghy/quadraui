- GTK's `Spinner` rasteriser (`gtk::spinner::draw_spinner`) now paints through
  `primitives::spinner::native_surface_paint::paint` via a `CairoSurface`
  instead of duplicating the glyph-table lookup and glyph+label text-building
  logic that painter already carries (#2509). `gtk_spinner_layout` measures
  the same shared `spinner_text` string instead of rebuilding it from a
  private local frame table. `gtk::activity_bar` and `gtk::panel` already
  delegated their painting to shared primitives; no behavior change.
