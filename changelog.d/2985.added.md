- `Backend::note_widget_paint` — a no-op-by-default hook
  `DrawsPrimitives::draw_dyn` calls once per paint, handing the backend
  the resolved layout and rect for the widget it just painted, so a
  backend that keeps a per-`WidgetId` geometry cache for its own bespoke
  `draw_*` path can keep that cache in step when the same widget is
  painted through the widget contract instead (#2985). `TuiBackend` and
  `GtkBackend` override it to record a `TabBarPrimitiveLayout`'s
  `(bar rect, TabBarLayout)` pair, which is what
  `TuiDriver::tab_center` / `tab_close_center` (and their `GtkDriver`
  twins) resolve a specific tab's body or close glyph from; every other
  widget's layout is ignored. No consumer implements `Backend` (it is
  in-tree-only), and the method has a default body, so nothing outside
  this repo has to change.
