- Core row windowing for `ListView`, `TreeView`, `DataTable` and
  `TextDisplay`: an `items_window: Option<ItemsWindow>` descriptor field
  (`ItemsWindow { start, total }`, now in `quadraui::behaviour::row_window`)
  plus `scroll_px`, and `UiEvent::RowsRequested { id, start, count }`, sent
  through the new `Interactive::data_requested` hook when navigation or
  scrolling reaches rows the app has not loaded. Unloaded rows paint as
  placeholders. The Python and Node bindings deliver `RowsRequested` with
  the same wire shape as before, now from the core widgets.
