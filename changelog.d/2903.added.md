- `quadraui::widget_kinds!` macro + `quadraui::decode_widget`/`quadraui::KindError`
  (#2903): a `kind` string → descriptor type registry that decodes a
  JSON-shaped widget payload into a boxed `Box<dyn DynWidget>` without the
  caller knowing which concrete `Primitive` type that kind names, seeded
  with the `"cell_grid"`/`"icon_grid"` entries. A table entry may carry
  attributes, so a descriptor whose `Primitive`/`Interactive` impls are
  gated on a backend feature (`"icon_grid"`) joins the table under the same
  `#[cfg(…)]` and reads as `KindError::Unknown` on a build without one.
