- `FormController` now gives a `Form`-embedded `FieldKind::Slider` field a
  real click/drag/key arm (#2587): a click or drag on the field's painted
  track maps the pointer's x position to a value, and Left/Down, Right/Up,
  Home/End step or jump a focused `Slider` field's value, each emitting
  `FormEvent::SliderChanged` — previously `form_click_event` fell through
  to `FormEvent::FocusChanged` and there was no key handling at all, so
  the only way to move a `Slider` field's value was the a11y
  Increment/Decrement action. The track rect comes from the field's new
  `VisibleFormField::item_bounds` entry, which every layout path now
  populates (`layout_metrics::form_field_measure` for the pixel backends,
  `tui::form`'s cell-unit measure, and `FormController`'s own
  backend-free fallback), so a labeled field — `LabelPosition::Left`, the
  form-wide default — is as click/drag-operable as an unlabeled one, and
  a press on the label column or the value text only focuses the row
  instead of snapping the value to a bound.
