- `Switch::hovered`/`Switch::pressed` and `RadioOption::hovered`/`RadioOption::pressed`
  (#2512): optional, host-set hover/pressed flags on the descriptors
  themselves, following the same convention `Switch::focused`/`RadioGroup::focused`
  already use. `Backend::draw_switch`/`Backend::draw_radio_group` read these
  directly to tint hover/pressed state, so one call covers both the resting
  and the tinted paint without a separate `InteractionState`.
