- `UiEvent` is now `#[non_exhaustive]` (#2777): a downstream `match` on
  `quadraui::UiEvent` must add a wildcard arm (`_ => {}`) to keep compiling.
  Existing variants and construction are unaffected — this only closes off
  adding a new variant (`Backend::poll_events` can grow more event kinds
  going forward) from being a breaking change. Zero hits in `vimcode` or
  `coord-tui`: both already fall through an `other =>`/`_ =>` arm on every
  `UiEvent` match, so neither needs a migration.
