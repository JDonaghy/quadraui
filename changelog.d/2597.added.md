- `TreeTable` (#2597): a `DataTable` plus per-row tree metadata
  (`TreeTableNode`: path, indent, expand state, optional icon), built by
  composition rather than as a parallel primitive — `TreeTable::layout`
  calls `DataTable::layout` and lays out column 0's tree cell on top,
  and `TreeTableLayout::hit_test` adds a `Chevron` hit to everything
  `DataTableLayout::hit_test` already resolves. TUI paints it through
  `tui::draw_tree_table` (`tui::data_table`'s painter, reusing `tree::
  paint_tree_cell` for column 0 and `compose::tree_nav::TreeNavCore::
  horizontal_nav` for Left/Right); `Backend::draw_tree_table`/
  `tree_table_layout` default to painting a plain `DataTable` (no tree
  decoration) until GTK/macOS/Win gain their own rasteriser. On a narrow
  TUI rect, `tree_table_layout` drops the rightmost columns (never the
  tree column itself) before ever truncating column 0 below indent +
  chevron + one label character. `TreeTableEvent::ToggleExpanded` is
  emitted by `TreeTableLayout::chevron_toggle` (chevron click) and
  `TreeTableEvent::from_horizontal_nav` (Left/Right), both used by the
  gallery demo. Demonstrated by the gallery's new "Tree Table" demo (a
  small file tree with Name / Date Modified / Size / Kind columns).
