- `Primitive::text_region` (#2977): a primitive reports the selectable
  text it painted, and `draw_primitive`/`draw_dyn` register it through
  `Backend::register_text_region`, so drag-select and copy work on it on
  every host. `MessageList` reports its painted transcript rows.
- `quadraui_binding_core::widget_leaf_kinds()` (#2977): the kinds a
  binding's layout leaf or flat render dict decodes as a generic widget —
  the built-in generic kinds plus every kind registered at runtime with
  `quadraui::register_widget_kind`. A runtime-registered kind now decodes,
  paints and routes through binding-core with no table edit, so a host
  binding outside py/node can add widget kinds of its own.
