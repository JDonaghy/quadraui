- `UiEvent::Scroll` now routes into the widget contract as
  `RoutedEvent::Wheel`, hit-tested and delivered to the widget under the
  cursor — the wheel counterpart of the existing `MouseDown` /
  `DoubleClick` arms, which left `RoutedEvent::Wheel` unreachable for
  every contract widget (#2825). A widget that ignores the wheel still
  lets the plain `UiEvent::Scroll` reach `AppLogic::handle` unchanged, so
  existing wheel handling is unaffected.
