- Added `A11yNodeId::from_raw` (#2715): rebuilds a node id from its raw
  `as_u64` form, the only shape an out-of-process caller ever sees (a
  `control::ControlRequest::Snapshot` reply's JSON `id` field). Needed by
  the new `quadraui-mcp` crate's `act` tool, which only ever receives that
  raw number back from an MCP client.
- Added `quadraui-mcp`, a new workspace crate: an MCP (Model Context
  Protocol) server exposing a running `quadraui::control::ControlHandle`
  as JSON-RPC tools (`snapshot`, `act`, `key`, `type`) over stdio or a
  Unix-domain socket, so an AI agent can drive any `quadraui` app while a
  person watches the live TUI or window.
