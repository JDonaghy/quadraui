- `items_window` wire extension key for `ListViewDescriptor`/`TreeViewDescriptor`/
  `DataTableDescriptor`/`TextDisplayDescriptor` (#2531): a render callback can now
  set `{"items_window": {"start": ..., "total": ...}}` alongside its `"items"`/
  `"rows"`/`"lines"` payload to say "this is only a `start..start+len` slice of
  `total` real rows", decoded via `quadraui-binding-core`'s new
  `render::items_window_from_value`. Paired with the new
  `render::rows_requested_for_window`, which computes the bounded `{id, start,
  count}` window (`RowsRequestedEvent`) a binding should ask its app to re-render
  with once scrolling moves outside the currently loaded slice — never proportional
  to `total`, so a 100k-row table with a 50-row window only ever asks for a few
  hundred rows at a time. A descriptor that never sets `items_window` is
  completely unaffected.
