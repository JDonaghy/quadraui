- `win::run`/`win::run_with`/`win::shell_runner::run_with_shell` now
  return `Result<(), quadraui::RunError>` instead of
  `std::process::ExitCode` (#2838): the shared `RunError` seam (#2834)
  every backend's `run`/`run_with` converges on, completing the TUI
  (#2835), GTK (#2836), and macOS (#2837) migrations. A caller's `fn main`
  that previously ended in `quadraui::win::run(app)` with a `->
  std::process::ExitCode` signature changes that signature to `->
  Result<(), quadraui::RunError>` (or, to keep `ExitCode` ergonomics,
  matches on the result and calls `RunError::report`); a
  `run_with_shell(app, config)` caller that previously ignored the return
  value should now propagate or match it instead. A failed native Win32
  call now arrives as `RunError::Backend(BackendError::PlatformFailure
  { .. })` with the failing call's name and HRESULT message intact,
  instead of being summarized away into a bare exit code; a headless
  `QUADRAUI_WIN_SMOKE_MS` self-check failure arrives as
  `RunError::Code(1)`.
