- `quadraui::decode_widget_from` (#3009): `decode_widget`'s
  deserializer-taking twin, generated by the same `widget_kinds!` macro
  invocation and matching the same `kind` → descriptor-type table, but
  decoding out of any `serde::Deserializer` instead of an owned
  `serde_json::Value`. A wire layer with its own unknown-key policy
  substitutes its wrapping deserializer here and gets each descriptor
  type's field list through `deserialize_struct`, so a typo'd key inside
  a `"button"`/`"switch"`/`"radio_group"`/`"cell_grid"`/`"icon_grid"`
  descriptor body is reported rather than silently ignored — the same
  treatment a fixed leaf's own body already got. An unknown `kind` is a
  `serde::de::Error::custom` message rather than a `KindError`, since the
  error type is the deserializer's own; `decode_widget` is unchanged.
