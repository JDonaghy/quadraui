- `StatusBar` and `ActivityBar` implement the widget contract (#2871):
  `Primitive` (measure, layout, pixel paint and cell paint in the widget's
  own module) plus `Interactive`, so either can be pushed as a
  `Surface::Widget` and registered in a `FrameTree`. `StatusBar` is
  pointer-only — hover tracks the clickable segment under the pointer, a
  left press arms it and captures the pointer, and a release over the same
  segment emits `StatusBarSegmentAction::SegmentClicked`, riding
  `UiEvent::StatusBar(id, SegmentClicked)`. `ActivityBar` is one keyboard
  focus stop whose cursor Up/Down walk through `behaviour::nav::FlatNav`
  (saturating, not wrapping), with click and Enter emitting
  `ActivityBarAction::ItemActivated` as
  `UiEvent::ActivityBar(id, ItemClicked)`; a right click and the vim-style
  keys a host maps itself are deliberately left unclaimed.
  `quadraui::tui::draw_status_bar` is now a thin delegate onto the
  widget-owned cell painter, which paints through `CellSurface`: segment
  text advances by display width, so a double-width glyph takes two
  columns instead of being written narrow in the bar's last column.
- New on the status-bar primitive: `StatusBarPrimitiveLayout`,
  `StatusBarState` (with the shared `hover`/`press`/`release` state
  machine `compose::StatusBarInteraction` now adapts `UiEvent`s onto),
  `StatusBarRelease`, `StatusBar::segment_at`, `cell_layout`,
  `MIN_GAP_CELLS` and `PIXEL_MIN_GAP` (the one pixel gap constant, no
  longer a private copy inside the shared painter).
- New on the activity-bar primitive: `ActivityBarPrimitiveLayout`,
  `ActivityBarState` (which owns the cursor model
  `compose::AppShell`'s activity-bar keyboard handle now delegates to, and
  implements `PaintState::hovered_idx`), `ActivityBarAction`,
  `ActivityBar::{item_count, item_at, logical_index_of, pixel_layout}`,
  and the `PIXEL_ROW_HEIGHT` / `PIXEL_ROW_HEIGHT_CELLS` /
  `CELL_BAR_WIDTH` constants — `gtk::ACTIVITY_ROW_PX`,
  `macos::ACTIVITY_ROW_PX` and `win::ACTIVITY_ROW_DIP` are now spellings
  of that one shared row height rather than independent copies.
