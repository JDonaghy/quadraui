- `quadraui-binding-core::scripted::ScriptedPrimitive` (#2614): a
  `quadraui::primitive::Primitive` backed by a script-side `ScriptWidget`
  (`measure`/`paint`/`on_event`/`a11y` callbacks), drawn through
  `DrawsPrimitives::draw_primitive` on every backend and reusing the
  `Canvas` `DrawOp`/`CanvasRegion` display list verbatim — no new op set.
  Caches the script's `measure`/`paint` answer keyed on `(props, rect,
  theme)` so an unchanged frame makes no further script calls.
  `quadraui::primitives::canvas::native_surface_paint::paint` is now `pub`
  and unconditional (previously `pub(crate)`, gated to the `gtk`/`macos`/
  `win` features) so this and any other out-of-crate `PaintSurface`
  implementor can replay a `Canvas`-shaped display list without a second
  op-to-verb translator.
