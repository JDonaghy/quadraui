- `primitive::LayoutCtx` now carries the calling backend's text measurer and
  is built with `LayoutCtx::new(line_height, char_width, nerd_fonts_enabled)`
  instead of a struct literal (#2991) — **breaking**: the type gains a
  lifetime parameter and a private `measurer` field. `LayoutCtx::text_width`
  measures through `Backend::measure_text` for a given `FontRole` when
  `DrawsPrimitives::draw_primitive`/`draw_dyn` attached one (via the new
  `LayoutCtx::with_measurer`), and falls back to `char_width * chars` for a
  ctx built with no backend in reach. `TabBar`'s `Primitive::layout` sizes
  tab labels, close glyphs and right segments through it, so its shared
  pixel layout now places tabs where each pixel rasteriser paints them
  instead of at a `char_width` approximation that ellipsised labels the
  rasteriser fits. The runtime's own widget pointer routing attaches the
  same measurer before resolving the layout it hit-tests against, so a
  click at a painted tab's centre can no longer activate its neighbour on
  a proportional chrome font.
