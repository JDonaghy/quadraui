- `quadraui::layout::GridTrack` and `resolve_grid_tracks` (#2686): a
  backend-neutral `Fixed`/`Percent`/`Weight`/`Content` track-sizing
  vocabulary resolves a list of column tracks and a list of row tracks
  against a container `Rect` into a 2D grid of cell `Rect`s, through the
  same Fixed+Content → Percent → Weight pass order
  `resolve_main_axis_sizes` uses for a `LayoutContainer`'s children.
  `resolve_grid_areas` resolves a CSS-style `grid-template-areas`
  template into a map from area name to the `GridAreaSpan` of cells it
  spans, and `grid_area_rect` unions a span's cells back into one `Rect`.
  Pure math — no primitive, backend, or wire change yet; a future issue
  builds a `Grid` primitive on top of it.
