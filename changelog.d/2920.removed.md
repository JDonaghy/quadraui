- Removed `compose::CellGridController`/`CellGridControllerEvent` (#2920):
  `CellGrid`'s own `Interactive` impl (#2918) now covers everything the
  controller did, so the two-path coexistence that landed alongside it
  ends here. `CellGrid` gains `CellGrid::new(id)` and is now
  `#[non_exhaustive]` — a struct-literal construction from outside this
  crate (every field but `id` was previously settable that way) no
  longer compiles; build one with `CellGrid::new(id)` and set the fields
  you need on the result instead. `examples/common/cell_grid_demo.rs`
  drives `CellGrid` directly through `Interactive` via its own hand-rolled,
  per-band dispatch (mirroring `data_table_app.rs`'s existing pattern)
  rather than a bespoke controller.
