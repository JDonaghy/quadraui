- `CellGrid` gains two opt-in visual aids, both off by default (#2929):
  `column_separators` paints a `theme.separator` `│` at every body/header
  column's right-edge cell on TUI (no effect on a pixel backend, which
  already draws gridlines), and `striped` tints every other non-frozen
  body row with `theme.row_alt_bg` on every backend, by absolute row
  index so the stripe survives scrolling. Both are plain `pub` fields
  with `CellGrid::with_column_separators`/`with_striped` builders.
