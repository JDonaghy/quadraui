- A `Form`'s `FieldKind::Slider` field now reports its painted track as a
  single `VisibleFormField::item_bounds` entry on every backend, and both
  the shared pixel painter and the TUI painter draw the track into that
  exact rect, so paint and click routing can't drift apart (#2587). On
  the pixel backends the track keeps a fixed natural width
  (`layout_metrics::pixel::FORM_SLIDER_TRACK_WIDTH`) rather than
  stretching with the field's resolved `ControlWidth` — the same tradeoff
  `FieldKind::NumberInput`'s item-bounds-driven control box already
  makes. The TUI painter still stretches with `ControlWidth`, and its
  reported track rect grows with it.
