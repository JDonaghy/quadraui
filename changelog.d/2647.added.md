- `crate::primitive::Primitive::paint_cells` (`feature = "tui"`) and
  `crate::tui::backend::TuiBackend::draw_primitive` (#2647): a `Primitive`
  now has a TUI paint story — `TuiBackend::draw_primitive` resolves
  `Primitive::layout` then calls the new cell-buffer-flavored
  `paint_cells` method instead of the pixel-shaped `PaintSurface`-based
  `paint`, which TUI can never meaningfully supply. `ListView`'s pilot
  `impl Primitive` now covers TUI too, delegating `paint_cells` straight
  to `crate::tui::draw_list` so painting it through `Primitive` on TUI is
  byte-for-byte identical to `TuiBackend::draw_list`. Defaults to a no-op,
  so every existing `Primitive` implementor with no TUI story compiles
  unchanged.
