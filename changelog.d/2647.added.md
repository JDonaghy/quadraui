- `crate::primitive::Primitive::paint_cells` (`feature = "tui"`) and
  `crate::backend::Backend::cell_buffer` (#2647): a `Primitive` now has a
  TUI paint story reachable through `&mut dyn Backend` — the shape every
  `compose::*` controller's `render` is handed, same as the
  pixel-backend path through `Backend::paint_surface`.
  `DrawsPrimitives::draw_primitive`'s default body resolves
  `Primitive::layout`, then calls the new cell-buffer-flavored
  `paint_cells` method whenever `Backend::cell_buffer` answers `Some`
  (`TuiBackend`'s case) instead of the pixel-shaped `PaintSurface`-based
  `paint`, which TUI can never meaningfully supply. `ListView`'s pilot
  `impl Primitive` now covers TUI too, delegating `paint_cells` straight
  to `crate::tui::draw_list` so painting it through `Primitive` on TUI is
  byte-for-byte identical to `TuiBackend::draw_list`. Both new methods
  default to a no-op/`None`, so every existing `Backend`/`Primitive`
  implementor with no TUI story compiles unchanged.
