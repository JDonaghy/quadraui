- `ToolbarButton::Group` (#2593): a bordered cluster of `Action`/`Label`
  children — a back/forward pair sharing one pill, or an exclusive segmented
  view-mode switcher — laid out as one item in the toolbar's main-axis pack
  through a new shared `layout_group_children` helper, so every backend
  measures/paints/hit-tests the group's children from the same geometry.
  Clicking a child of an `exclusive: true` group reports the new
  `ToolbarEvent::GroupSelected { group, id }` (now `#[non_exhaustive]`)
  instead of `ButtonClicked`; a non-exclusive group keeps the plain
  `ButtonClicked` contract. GUI backends paint one shared border/background
  around the group with 1px dividers and the active child filled with
  `theme.selected_bg` through `primitives::toolbar::native_surface_paint`'s
  new `paint_group`; TUI paints a `[ a │ b │ c ]` bracket-and-divider frame
  around each child's own existing format. Reachable from bindings via the
  wire `ToolbarButtonDescriptor`'s new `Group` variant and
  `ToolbarEvent`'s new `GroupSelected` payload.
